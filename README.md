Token Launch Radar (radar-3): ranks 198 pre-token protocols by implied launch value — from each protocol's TVL, its 7-day growth, and how long it has run with no token recorded — with a 9-step farm plan (cost and time on every step) for each one. The 40-protocol watchlist (TVL ≥ $50M, no token recorded) is fully covered, and wrapped, staked and bridged products are set aside from the ranking, so the top of the board is launch-like: rank 1 is Sentora Curator ($185.3M implied), followed by Steakhouse Financial, Gauntlet and Veda. The dashboard is a static page with no network: a sortable, filterable board, a detail view per protocol with a model breakdown, and a separate tab for protocols whose token already trades.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
